# AI Use Declaration

**Project:** Pinawe IT Helpdesk website
**Unit:** IS229 — Web Design
**Assessments covered:** Assessment 2 and Assessment 3
**AI tool used:** Claude (Anthropic)
**Student:** Lydia Sapmangua

## Summary

An AI assistant (Claude) was used throughout the development of this website,
for both HTML/content scaffolding (Assessment 2) and CSS/responsive styling
(Assessment 3), and for command-line guidance while setting up Git and
publishing to GitHub Pages. All AI-generated material was reviewed, tested in
a browser, corrected, and committed.

## Detailed breakdown

| Area | What the AI did | What the student did |
|---|---|---|
| Page structure (A2) | Generated the initial semantic HTML5 structure for five pages (Home, About, Services, Knowledge Base, Contact), including headings, nav, forms and tables | Reviewed the structure, edited content, confirmed it met the assessment's semantic HTML requirements |
| Page content (A2) | Drafted placeholder text for a fictional IT helpdesk business ("Pinawe Software Co."), including service descriptions, support tiers and ticket form fields | Reviewed and can explain all content; would personalise further before a real submission |
| Contact form (A2) | Generated form fields, labels and HTML5 validation attributes (`required`, `pattern`, `minlength`, etc.) | Tested the form in the browser and confirmed validation behaviour |
| CSS design system (A3) | Generated `css/style.css`: colour variables, typography scale, spacing scale, Flexbox layouts (navigation, buttons, footer), CSS Grid layouts (hero, cards, forms, sidebar), mobile-first media queries at ~600px and ~960px, and visible focus states | Reviewed the CSS against the assessment rubric, tested the live site at multiple screen widths using Chrome DevTools, and identified/fixed issues (e.g. stylesheet file location) |
| Placeholder images (A3) | Generated simple SVG graphics (logo, hero illustration, team graphic, and six service icons) as stand-ins for real artwork, since none had been supplied | Some icons were replaced with the student's own images; placeholders were added to the correct project folder and committed |
| Git and GitHub setup | Provided step-by-step terminal commands for initialising Git, committing, creating a GitHub repository, connecting it as a remote, and publishing with GitHub Pages | Typed and ran every command personally, and worked through several real errors (wrong folder, typos, a duplicate remote address, a stray character in the repository name) with AI guidance at each step |
| Troubleshooting | Diagnosed errors from screenshots of the terminal and browser console (e.g. `fatal: remote origin already exists`, `404` errors for missing images) and explained the cause and fix | Made every actual change to the project files and repository; confirmed each fix worked before moving on |
| Documentation | Drafted the structure and wording for `README.md` and this declaration | Reviewed and will personalise details (contact information, final URLs) before submission |

## What was not AI-generated

- The final choice of business concept and any changes to placeholder content beyond what is listed above.
- All actual typing of commands and file edits in Command Prompt, VS Code, and GitHub's website.
- The decisions about which errors to fix and in what order.
- Final review of the live, published site.
